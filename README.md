# BMI Calculator

เว็บคำนวณ BMI แบบ static (HTML/CSS/JS ล้วน ไม่มี backend และไม่ต้อง build) ข้อมูลทั้งหมดเก็บใน localStorage ของเบราว์เซอร์

## คู่มือการใช้งาน

### 1. คำนวณ BMI
1. เลือกหน่วย **Metric** (kg · cm) หรือ **Imperial** (lb · in) ค่าที่กรอกไว้จะถูกแปลงหน่วยให้อัตโนมัติ
2. กรอก **ส่วนสูง** และ **น้ำหนัก** ในช่อง หรือลาก slider ใต้ช่อง
3. ผลลัพธ์ฝั่งขวาอัปเดตทันที ไม่ต้องกดปุ่มคำนวณ

ผลลัพธ์ประกอบด้วย ค่า BMI, หมวดน้ำหนัก, ตำแหน่งบนแถบสเกล, ช่วงน้ำหนักที่เหมาะสมกับส่วนสูง และน้ำหนักที่ควรเพิ่มหรือลดเพื่อเข้าเกณฑ์ปกติ

หากกรอกค่านอกช่วงที่รองรับ (ส่วนสูง 100–220 cm, น้ำหนัก 20–200 kg) ช่องจะขึ้นกรอบแดงพร้อมข้อความเตือน

### 2. เลือกเกณฑ์ประเมิน
ปุ่ม **เอเชีย / WHO** บนแถบเครื่องมือ

| หมวด | เอเชีย | WHO |
|---|---|---|
| น้ำหนักน้อย | < 18.5 | < 18.5 |
| ปกติ | 18.5 – 22.9 | 18.5 – 24.9 |
| น้ำหนักเกิน / ท้วม | 23 – 24.9 | 25 – 29.9 |
| อ้วนระดับ 1 | 25 – 29.9 | 30 – 34.9 |
| อ้วนระดับ 2 | ≥ 30 | 35 – 39.9 |
| อ้วนระดับ 3 | – | ≥ 40 |

### 3. ข้อมูลเพิ่มเติม (ไม่บังคับ)
กดเปิดหัวข้อ **ข้อมูลเพิ่มเติม** แล้วกรอก เพศ, อายุ, รอบเอว และระดับกิจกรรม เพื่อปลดล็อกการ์ดดังนี้

- **พลังงานที่ร่างกายต้องการ** (ต้องมีเพศและอายุ): แสดง BMR, TDEE และแคลอรีสำหรับลด คงที่ หรือเพิ่มน้ำหนัก ใช้ได้กับผู้ที่อายุ 18 ปีขึ้นไป
- **รอบเอวต่อส่วนสูง** (ต้องมีรอบเอว): ควรต่ำกว่า 0.5 และถ้าระบุเพศ จะเทียบกับเกณฑ์รอบเอวของคนเอเชีย (ชาย 90 cm, หญิง 80 cm)

### 4. บันทึกและดูแนวโน้ม
- กด **บันทึกผลนี้** เพื่อเก็บค่าปัจจุบันเข้าประวัติ
- กราฟด้านล่างแสดงแนวโน้ม สลับดูเป็น **BMI** หรือ **น้ำหนัก** ได้ ต้องมีอย่างน้อย 2 รายการ แตะหรือลากบนกราฟเพื่อดูค่าแต่ละจุด
- กด **×** ท้ายแถวเพื่อลบรายการนั้น หรือ **ล้างประวัติ** เพื่อลบทั้งหมดของโปรไฟล์

### 5. ตั้งเป้าหมายน้ำหนัก
1. กรอก **น้ำหนักเป้าหมาย** และเลือก **อัตราการเปลี่ยนแปลง** ต่อสัปดาห์ (0.25 – 1 kg)
2. กด **ตั้งเป้าหมาย**
3. ระบบแสดงแถบความคืบหน้า น้ำหนักที่เหลือ วันที่คาดว่าจะถึงเป้า และแคลอรีที่แนะนำต่อวัน (ถ้ากรอกเพศและอายุไว้)

ถ้าแคลอรีที่แนะนำต่ำกว่า BMR ระบบจะเตือนให้ลดอัตราลง เมื่อถึงเป้าหมายจะมีเอฟเฟกต์ฉลอง

### 6. หลายโปรไฟล์
ใช้ตัวเลือกโปรไฟล์บนแถบเครื่องมือ: **＋** เพิ่ม, **✎** เปลี่ยนชื่อ, **🗑** ลบ แต่ละโปรไฟล์มีข้อมูล ประวัติ และเป้าหมายแยกกัน เหมาะกับการติดตามคนในครอบครัว

### 7. แชร์ ส่งออก และสำรองข้อมูล
| ปุ่ม | ทำอะไร |
|---|---|
| **แชร์** | แชร์ผลเป็นลิงก์ (มือถือเปิดเมนูแชร์ ส่วนคอมพิวเตอร์คัดลอกลิงก์) เมื่อมีคนเปิดลิงก์ จะสร้างโปรไฟล์ "ที่แชร์มา" แยกให้ ไม่ทับข้อมูลเดิม |
| **Export CSV** | ดาวน์โหลดประวัติของโปรไฟล์ปัจจุบัน เปิดใน Excel ได้ |
| **พิมพ์ / PDF** | เปิดหน้าพิมพ์ เลือก "บันทึกเป็น PDF" |
| **สำรองข้อมูล** | ดาวน์โหลดข้อมูลทุกโปรไฟล์เป็นไฟล์ JSON |
| **กู้คืนข้อมูล** | นำไฟล์ JSON กลับเข้ามา โดยจะแทนที่ข้อมูลปัจจุบันทั้งหมด |

### 8. การตั้งค่าอื่นๆ
- **TH / EN**: สลับภาษา
- **ไอคอนพระจันทร์/ดวงอาทิตย์**: สลับธีมมืด/สว่าง
- **เสียง**: เปิดเสียงแจ้งเตือนสั้นๆ ตอนฉลอง (ปิดไว้เป็นค่าเริ่มต้น)
- **ติดตั้งแอป**: ปุ่มจะปรากฏเมื่อเบราว์เซอร์รองรับ ติดตั้งแล้วใช้เป็นแอปบนมือถือหรือคอมพิวเตอร์ได้

### ข้อควรรู้
- ข้อมูลเก็บในเบราว์เซอร์เครื่องนี้เท่านั้น ไม่ส่งไปที่ใดและไม่ซิงก์ข้ามเครื่อง หากล้างข้อมูลเบราว์เซอร์ข้อมูลจะหาย ควรกด **สำรองข้อมูล** เป็นระยะ
- BMI ไม่แยกมวลกล้ามเนื้อออกจากไขมัน ผู้ออกกำลังกายหนักอาจได้ค่าสูงกว่าความเป็นจริง
- ผลลัพธ์เป็นข้อมูลเบื้องต้น ไม่ใช่การวินิจฉัยทางการแพทย์ หากกังวลเรื่องสุขภาพควรปรึกษาแพทย์
- ผู้ที่อายุต่ำกว่า 18 ปีควรใช้กราฟการเจริญเติบโตตามอายุและเพศ แอปจะแสดงคำเตือนเมื่อกรอกอายุต่ำกว่า 18

## รันในเครื่อง

```
npx serve .
```

หรือเปิด `index.html` ตรงๆ ได้ (ฟีเจอร์ PWA/ออฟไลน์ต้องรันผ่าน http เท่านั้น)

## Deploy บน Vercel

```
npm i -g vercel
vercel --prod
```

หรือ push ขึ้น GitHub แล้ว Import Project ใน Vercel โดยตั้ง Framework Preset เป็น **Other** ไม่ต้องใส่ Build Command

## ฟีเจอร์

- คำนวณ BMI เกณฑ์เอเชียและ WHO, สลับหน่วย Metric/Imperial, ไทย/อังกฤษ, Dark/Light
- หลายโปรไฟล์, ประวัติการคำนวณ, กราฟแนวโน้ม BMI/น้ำหนัก
- เป้าหมายน้ำหนัก พร้อมเวลาโดยประมาณและแคลอรีที่แนะนำ
- BMR/TDEE (Mifflin-St Jeor), สัดส่วนรอบเอวต่อส่วนสูง
- แชร์ผลผ่านลิงก์, Export CSV, พิมพ์/PDF, สำรอง/กู้คืน JSON
- PWA ติดตั้งเป็นแอปและใช้ออฟไลน์ได้

## หมายเหตุ

ใช้เป็นข้อมูลเบื้องต้นเท่านั้น ไม่ใช่การวินิจฉัยทางการแพทย์ โหมดเด็ก/วัยรุ่นแบบเปอร์เซ็นไทล์ยังไม่รองรับ (ระบบจะแสดงคำเตือนเมื่ออายุต่ำกว่า 18 ปี)
